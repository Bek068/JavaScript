# JS_CODE

This repository tracks my JavaScript learning journey through a structured set of folders and practice files.

I started with the fundamentals in `1_Section`, covering variables, data types, strings, numbers, dates, comparison, and type conversion. From there, I moved into `2_Section` for arrays and objects, then `3_Section` for functions, arrow functions, scope, and IIFE examples. The later folders focus on control flow and looping practice, with small exercises such as personalized messages, duplicate checks, averages, `forEach`, higher-order array loops, and `reduce`.

Alongside the section-based practice, files like `calculator.js` and `maskinganEmail.js` show the small projects and utility exercises I have been building while following the "Chai Aur Code" JavaScript course playlist available on Youtube by Hitesh Choudhary.

So far, I have completed around Day 30 of the course and kept moving through the core JavaScript topics step by step.# JavaScript
